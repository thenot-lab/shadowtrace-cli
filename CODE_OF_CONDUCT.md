# Code of Conduct

## The short version

Be the kind of person you'd want investigating you with this tool.

## The slightly longer version

Shadowtrace is a tool that intersects with people's lives. Contributors and users alike are expected to:

- **Treat subjects as people, not targets.** Even public figures have private lives. The tool's defaults are conservative because most operators won't think about this; you should.
- **Treat other contributors with respect.** Disagreement is fine; contempt is not.
- **Disclose conflicts.** If you're contributing code that affects how a particular class of subject (your employer's competitors, a public figure you have history with) is researched, say so.
- **Don't use the project to harass.** This includes harassment of subjects via shadowtrace and harassment of contributors via the issue tracker.

## Enforcement

Maintainers may close issues, reject PRs, and (in extreme cases) ban accounts that violate this code. Decisions are made by Dominion Labs maintainers and are not negotiable in public threads.

## Reporting

Report violations to conduct@dominionlabs.dev (or the contact on dominionlabs.dev). Reports are confidential.

## Attribution

This Code of Conduct is shadowtrace's own, written for the specific shape of this project. It is shorter than the Contributor Covenant on purpose — the rules above are the rules, not a starting point for legalistic interpretation.
